Documentation

This tool helps you work with a Toniebox 2 flash dump in a simple flow: open dump, edit files, crack/find UUID if needed, and save a patched image.

Quick Start

  1. Open Interface and choose Disk.
  2. Select your flash dump file and wait until loading is done.
  3. Open File Manager, choose a file, then use Save... or Replace....
  4. If a .crypt file needs a UUID, use Detect UUID.
  5. When finished, go back to Interface and click SAVE_IMAGE_TO_DISK.

Safety Checklist

  • Always keep one untouched backup of the original dump.
  • Work on a copy, not on your only source file.
  • Only flash modified images to your own device.
